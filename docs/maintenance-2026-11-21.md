# 2026-11-21 弹窗与发布验证

- 退场动画让弹窗在关闭后暂时保留在 DOM 中。React 提交更新时可能将焦点放回正在退场的弹窗，等节点移除后焦点落到页面主体。焦点管理现在会在提交完成后检查焦点是否仍在退场弹窗内，并还给打开弹窗的控件。
- 登录卡片的动画规则比减少动态效果规则更具体，导致系统开启该设置后动画仍会播放。修正选择器优先级，并更新浏览器测试以匹配当前登录和下载入口。
- 本地验证通过 75 项 Vitest、23 项 Worker 测试，以及 26 项 Playwright 回归。使用独立的本地 D1 和 R2 运行真实 Worker，验证浏览器注册和登录、同账号跨会话拉取地点和备注、原图和缩略图上传下载的 SHA-256、不同账号隔离、同步删除和退出登录。
- 简历表述草案：修复 PhotoMap 弹窗退场时的键盘焦点恢复与减少动态效果适配，补齐本地浏览器到 Cloudflare Worker、D1 和 R2 的联调验证。
